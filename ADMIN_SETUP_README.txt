GHS CAMPUS SAEEDPUR - ADMIN/CMS SETUP

This website includes Decap CMS at /admin/.
For editing to work, the Netlify project must be connected to a GitHub repository, Netlify Identity must be enabled, registration should be set to Invite only, and Git Gateway must be enabled.

After setup, an invited administrator can open:
https://ghs-campus-saeedpur.netlify.app/admin/

Admin can manage School Settings, Notices, Results, Gallery, Achievements, Downloads and Staff.
